# Slotter 1.0.0-alpha.1

Slotter saves named workspaces that open apps into zones across your monitors. You can also drag
windows into zones, snap with keyboard shortcuts, set up monitor plates and pin virtual desktop
plates with a bench for storing them. Changes save as you make them.

This is an alpha release. Virtual desktop detection uses undocumented operating system data and
may stop working after an OS update. The Windows executable is signed by Toby Kalkman using Certum
open source code signing. SmartScreen may still warn on a new download until the certificate builds
reputation. macOS requires Accessibility permission to move other apps' windows.

## Install

- **Windows**: download and unzip `Slotter-1.0.0-alpha.1-win-x64.zip`, then run `Slotter.exe`. It
  asks for administrator permission once so it can move elevated windows.
- **macOS**: open `Slotter-1.0.0-alpha.1.dmg`, drag Slotter to Applications, then open it and allow
  Accessibility permission when macOS asks.
